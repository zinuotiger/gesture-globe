## 实际手势用法

主页面点击 **手势图解**，展开 **看图做手势**。每项有摆手、动作、触发、效果；可播放轻量动作示意或切换静态图。左右手均允许，仅选一只主手；镜像方向按实际预览和当前反向设置理解。

| 操作 | 当前定义和条件 |
| --- | --- |
| 张掌旋转 | 五指张开、先稳定，再移动掌心；进入分类分数≥0.72连续4帧，保持≥0.55。静止不继续旋转 |
| 捏合缩放 | 拇指与食指靠拢保持，移动整只手；默认上移放大、下移缩小。进入距离/掌宽≤0.3连续3帧，退出≥0.4；不靠张开手指或向镜头前后推手 |
| 握拳暂停 | 收拢手指稳住拳头；分类≥0.65连续2帧；暂停手势，不关摄像头，也不禁用鼠标 |
| 食指选点 | 食指伸直，其余收拢；Pointing_Up≥0.72；屏幕指针命中球面并在同一区域停留650ms，漂移/背景会中断 |
| V字复位 | 食指与中指成V；分类≥0.78连续6帧，保持到复位完成。持续保持仅一次，退出姿势且冷却1200ms后才能再次触发。鼠标/按钮优先 |

这些分数是现有工程条件，不是让用户测分数，也不是已完成真人校准的声明。模型与推理设置未改。
