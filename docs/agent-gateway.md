# Optional agent gateway

TASK-801 exposes a data-only whitelist through `src/agent/index.ts`. It defaults off (`features.agent=false`). Explicit validated configuration enables a registry; this does not configure an LLM, backend, microphone or external service. P0 bootstrap does not import this optional module.

Registered executors are trusted composition code, never supplied by tool-call data. Unknown names, extra properties, accessors, nonfinite/out-of-range coordinates and queries beyond validated `agent.maxTextLength` are rejected. Unregistered tools report UNAVAILABLE. Results do not expose caught exception text or renderer objects. Arguments are copied and frozen before execution.

The current whitelist is focusLocation, resetView, selectGeo, resolveLocation, drawRoute and showWeather. View tools and external adapters are implemented by subsequent cards, not simulated here. The SDK/model license separation and public release block remain unchanged.

The added optional-agent text limit does not retune existing gesture parameters; configuration version remains 2026.09.3. Existing manual plans retain their original configuration hashes; consolidated acceptance must capture the final full configuration.

TASK-802 adds AgentContextBuilder. It copies finite validated view scalars, selected latitude/longitude, enabled registered tool names and fixed schema/config versions. It deliberately omits selection/session/device identifiers, city metadata, diagnostics, camera/vision objects, frames, landmarks and credentials. Extra fields are never traversed, including getters. Required fields must be own data properties; resulting snapshots are deeply frozen. No context is uploaded or persisted by this module.

TASK-803 adds `registerViewTools(registry, app.agentPort)` using the same `monotonicNow` clock as M06. `bootstrapApp` exposes the narrow port only with explicit `features.agent=true`. It accepts only Agent input, provides a read-only view, cancellation and structured interaction observations; it does not expose Three.js or lock internals. The application does not import M12: an optional composition entry imports the public App and Agent interfaces, as demonstrated in tests/fixtures/agent.html.

focusLocation/resetView dispatch FOCUS/RESET through M06. selectGeo dispatches a validated SELECT_GEO action through the same source arbitration to the existing location selection/card/marker path. Longitude 180 normalizes to -180 for the Geo contract. A successful tool result means dispatch accepted, not completion of an animated transition. Mouse/keyboard/gesture priorities, stale rejection and command limits remain unchanged; cancellation uses M06's Agent-only source cancellation. Browser tests exercise a real rendered globe and actual mouse preemption without media activation.

TASK-804 supplies ExternalJsonClient and GeocodingAdapter. No provider is configured by default: requests return UNCONFIGURED, never sample coordinates. A separately authorized provider endpoint must implement `GET ?q=...` returning `{candidates:[{id,label,lat,lon}]}` JSON with unique IDs and valid coordinates. Endpoint selection is trusted composition configuration, never a tool argument. Credential/query-bearing endpoints and non-HTTPS remote endpoints are rejected; loopback HTTP is allowed for local integration tests. Requests omit credentials/referrer, reject redirects, bound UTF-8 JSON body bytes and time, and report rate limiting, HTTP/network/timeout/cancel errors without raw server messages.

Geocoding results retain configured source URL and actual fetch time. HTML/control characters, excess candidates, duplicate IDs and invalid coordinates reject the response. Every nonempty result, including a single candidate, awaits explicit `confirm(requestId,id)`; an old request cannot confirm a new result. Cancellation/supersession discards stale responses and returns CANCELLED for the old operation. Confirmation only returns validated coordinates; the caller must dispatch the chosen view/selection tool through M06.

Actual loopback HTTP was tested, including non-ASCII query encoding, rate limit, oversized body, timeout and pre-abort. No external provider account, API key or live geocoding service has been selected or tested. Real external service integration remains NOT_RUN/ACCEPTANCE_DEFERRED and requires a separately approved source/contract; local P0 operation does not depend on it.

TASK-805 adds ExternalDataAdapters for explicitly configured weather and route endpoints, using the same bounded HTTP transport. Weather parameters are lat/lon and the JSON contract is `{temperatureC,condition,observedAt}`. Route parameters are fromLat/fromLon/toLat/toLon and the contract is `{points:[{lat,lon}],distanceKm,durationMinutes,observedAt}`. Results retain separate source, fetchedAt and upstream observedAt fields. Text/temperature/coordinates/counts/timestamps are validated; missing services, rate limits, timeout, malformed data and cancellation are explicit failures, never sample weather or a generated route.

Validated route points dispatch DRAW_ROUTE through the Agent-only M06 source. A current user lock rejects the update. Geo owns one bounded depth-tested RouteOverlay; it interpolates arcs between supplied points only for display, does not calculate roads, and rejects ambiguous antipodal segments or excessive geometry. Default-off builds do not allocate the overlay. Successful replacement disposes old geometry; application disposal releases the overlay. Failed requests leave the previous displayed route intact while the latest data result explicitly reports failure.

Browser loopback tests exercise actual HTTP route delivery into the running Geo path and an actual weather HTTP 503; these are labelled fixtures, not real service evidence. Route/temperature fixture values are never used as product fallbacks. Actual provider correctness/terms/availability and human visual review remain NOT_RUN. User-facing progress/result controls are the next TASK-806 slice.

TASK-806 adds AgentActionCoordinator and optional `mountAgentControls(root, coordinator, config)`. The panel uses textContent and separate App/UI ports, never imports Agent internals. It shows indeterminate request/transition progress, source/fetch/observed times, readable failure messages, candidate coordinates for explicit disambiguation, cancellation and the latest successful pure-view undo. It does not simulate a language model. The default P0 entry remains Agent-off; tests/fixtures/agent.html is the explicit optional tool entry. Service endpoints are absent unless supplied by authorized composition; query parameters on this test entry configure only explicit endpoints, never credentials or model APIs.

App's animation loop calls coordinator.tick; M06 can renew only an already-owned active Agent transition, with the coordinator bounded by configured maximum transition duration plus one configured frame delta. This prevents the ordinary finite lease from expiring at the same boundary as the default reset animation. It never acquires a user-owned lease, renews network waits or creates a timer-owned lock. Explicit cancellation only releases an actually Agent-owned source, so it cannot clear another user's pointer work. Completion, failure, supersession, hiding and disposal release Agent ownership. Synchronous M06 observer callbacks mark/abort actions without re-entering command dispatch. Late results cannot restore cancelled state.

Undo stores one immutable view, transforms it back to a FOCUS input through M06, and restores prior auto-rotation only after completion. User input invalidates undo; geographic selections, routes, network results and permissions are not undone. Structured events are bounded by configured eventCapacity and contain only action number, whitelisted tool, status and time, with no request text or coordinates. Dispose clears retained action history/events.

AGT-001/002/010 map to registry/schema/config tests; AGT-003 to context redaction tests; AGT-004 to real bus/browser preemption; AGT-005/009 to HTTP/adapter and browser HTML-rejection tests; AGT-006/008 to action lifecycle, exact undo, bounded event and network-abort tests. AGT-007 voice remains explicitly disabled/outside this authorized implementation; no microphone request exists. External-provider and human visual acceptance remain deferred.
