## 依次观察

1. **摄像头与隐私：TASK-208/706。** 首次打开不应请求权限；显式点击启用后分别允许、拒绝、撤销权限。开关10次，关闭后亲自检查浏览器占用提示和设备灯熄灭；隐藏预览应保持识别，关闭摄像头才释放资源。检查网络和本地存储，无帧/完整关键点上传或持久化，无麦克风请求。详细步骤：[摄像头](camera-validation.md)、[隐私](privacy-validation.md)。
2. **真人手势：TASK-412/508/708。** 按最终矩阵覆盖左右手、0.5/1/1.5米、明亮/普通/可见暗光、简单/复杂背景；Open Palm、Pinch、Closed Fist、Pointing、Victory 每个浏览器版本每种手势至少20次独立开始，覆盖各维度而不是每行20次。记录成功/误判、进入退出耗时、跳变、重试；另做无手120秒、静止60秒、挥手60秒、Victory独立保持、Point扫过与停留。对照[最终矩阵](final-gesture-validation.md)的原验收阈值，禁止自动调低标准。
3. **稳定与性能：TASK-306/707。** `/tests/fixtures/stability.html` 点击开始采集，再单独显式启用真实摄像头，保持前台20分钟；按[稳定性协议](stability-validation.md)分别完成正常与慢推理条件、真实渲染/延迟分布、主线程与进程/Worker/GPU内存观察和诊断开关对照。停止或隐藏不能补成完整20分钟。`bitmap-harness.html` 的合成资源测试是补充，不替代真人运行。
4. **视觉、键盘与演示：TASK-612/710/806。** 在1366×768、1920×1080检查按钮/状态/地点卡/骨架遮挡、焦点与Escape、清晰错误、关闭入口；按[视觉协议](visual-validation.md)人工认可。按[演示脚本](demo-script.md)记录真实1–2分钟操作，并审查证据包。截图前隐藏摄像头，不保存原始视频。
5. **可选 Agent 与外部服务：TASK-804/805/806。** `/tests/fixtures/agent.html` 是显式启用工具的入口，不是聊天模型。输入坐标验证聚焦/选择/复位，观察进度，再取消、鼠标抢占、撤销一次纯视图操作；退出后无残留控制权。未配置服务时应明确显示不可用。真实地理编码/天气/路线测试必须先确定获准服务、来源版本/使用条款及其 JSON 契约，记录真实来源/数据时间、重名确认、失败/限流/取消、路线视觉；不得用 loopback fixture 代替服务验收，不自行添加账号、密钥或费用。

## 失败与结论

失败记录任务/步骤、实际环境、期望/实测差异、复现次数、时间戳和脱敏标量/错误文字。可保存隐藏摄像头后的界面截图、标量 JSON、脱敏网络元数据；不可保存原始帧、完整真人 landmarks、账号密钥或音视频。遇到权限/设备异常停止该项，不把重试成功抹去原失败。

用户真实确认后才可通过控制器正式签署对应门禁；本文件不构成确认。分别报告工程、自动测试、真实设备/外部服务及公开许可。模型仍为 EXTERNAL_LOCAL / UNRESOLVED / redistributionAllowed=false；公开发布保持 BLOCKED_PENDING_LICENSE，即使全部设备测试通过也不能自动解除。
