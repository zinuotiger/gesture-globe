# P0 fault coverage

TASK-705 combines source-level faults, contract/algorithm rejection tests and the canonical34-code P0 presentation catalog from requirements20.1. These are automatic engineering tests. Synthetic streams do not establish camera permission UX, physical unplug behavior or indicator extinction on real Chrome/Edge.

| Failure group                                                                                                    | Automatic evidence                                                                                                                                      |
| ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Permission denied / no device / busy / constraints / aborted / inactive document                                 | fault-matrix.spec.ts injects the six actual browser API rejection classes; one request except the bounded constraint retry                              |
| Missing MediaDevices or Worker                                                                                   | fault-matrix.spec.ts removes capability; no permission call, E-CAP-002, keyboard/manual globe remains                                                   |
| Pending grant cancelled / late stream /10 cycles/pagehide                                                        | camera-lifecycle.spec.ts, camera-acceptance.spec.ts; software track release and video detach                                                            |
| Video dimensions unavailable                                                                                     | fault-matrix.spec.ts keeps width0 through actual8-second deadline; tracks ended, Worker terminated, video detached                                      |
| Model absent/HTTP failure                                                                                        | gesture-runtime.spec.ts, error-center.spec.ts; explicit degradation and scoped retry                                                                    |
| WASM HTTP404                                                                                                     | fault-matrix.spec.ts real local loader, exactly two attempts/Workers then degradation                                                                   |
| Worker crash after actual local-model frame result                                                               | fault-matrix.spec.ts injects error events into real Workers; two results, one restart, two terminated Workers, mouse fallback                           |
| Heartbeat /3 inference errors / protocol mismatch / stale or reordered frames / old sessions / pending ownership | vision-health, vision-client/protocol/worker/scheduler unit and contract/integration suites; deterministic timing/transport faults                      |
| Invalid feature/NaN/hand loss / ambiguous hand / priorities / command source locks                               | gesture and interaction unit/integration fixtures; no invalid movement or lock bypass                                                                   |
| Texture404 / WebGL loss and failed restore                                                                       | globe-faults.spec.ts and error-center.spec.ts; actual WebGL extension loss/restoration, bounded retry/static fallback                                   |
| City HTTP/schema failure / stale lookup / invalid geographic values                                              | location.spec.ts and Geo unit/integration suites; coordinates retained, no stale selection overwrite                                                    |
| Invalid configuration/assets/hash/serialization                                                                  | config/asset/build contract tests; safe defaults or build failure, no model redistribution                                                              |
| Metrics API/invalid timing / high pressure                                                                       | clock/metrics/health tests, adaptive.spec.ts with labeled synthetic pressure; finite/unknown fallback and bounded policy                                |
| Storage denied / reduced motion / small layout / onboarding abort                                                | settings, onboarding and accessibility-layout E2E; fallback and keyboard controls                                                                       |
| All34 canonical P0 error codes and severities                                                                    | catalog derives rows from requirements20.1; ERROR/WARNING safe visible explanation, INFO quiet, FATAL static accessible fallback, no raw exception text |

The catalog test injects structured errors to verify presentation; it does not claim all34 underlying failures occurred on a physical device. Network/storage privacy review,20-minute real stability, native browser200% zoom and human visual confirmation retain their separate acceptance obligations.

The added missing-Worker test first failed on both viewport projects: the app checked media support but still requested permission without inference capability. The minimal App activation preflight now refuses that unsupported action with E-CAP-002 before camera permission. M03 continues to own only media capability/streams; it performs no gesture logic. Original failure traces remain in TASK-705-attempt1.
