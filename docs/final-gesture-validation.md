# TASK-708 最终真人矩阵

当前是工程准备完成后的空白验收协议，不是已完成的真人测试。新的 TASK-708-manual-plan.json 绑定当前配置版本与 SHA-256，保留 TASK-412 旧计划的哈希，不覆盖旧记录。配置仍为未实机调参的工程默认值。公开模型许可仍 UNRESOLVED / BLOCKED_PENDING_LICENSE。

Chrome 和 Edge 分别准备 CURRENT_MAJOR、PREVIOUS_MAJOR 两个记录位置。实际验收时核对并填写浏览器完整版本；这些标签不代表已安装、已运行或已通过。缺少某版本时记录 NOT_RUN 和限制，不把无头 Chromium 结果复制进来。每个位置独立记录匿名测试者、机器、OS、摄像头型号/分辨率、画质、时间及配置；不记录身份或设备唯一 ID。

先按 [摄像头协议](camera-validation.md)、[隐私协议](privacy-validation.md)、[视觉协议](visual-validation.md) 和 [稳定性协议](stability-validation.md) 完成相应实际观察。前置项缺证据时可以收集数据，但不得签署最终 PASS。

在本地开发服务打开应用，确认模型来自固定官方来源且已校验。明确启用摄像头，等待真实模型 READY，然后按 [真人手势协议](gesture-validation.md) 逐项执行五种手势。每种手势每个浏览器版本至少20次独立开始，覆盖左右手、0.5/1/1.5m、三档可见光线和简单/杂乱背景。每个环境的180行是组合记录模板，不要求每一行20次；720行总表不能被误称720次已执行测试。

每次先回到 READY/离开旧手势，记录成功或失败、误分类、进入/退出耗时、跳变、重试及环境。Open Palm、Pinch启动成功率目标≥90%；Pointing、Victory≥85%。Closed Fist按中断、松拳重建锚点和不跳变逐项验收，不能编造统一成功率。执行无手120秒、静止60秒、挥手60秒、Victory保持2秒、Pointing快扫20次及稳定停留20次，并记录鼠标抢占、丢手、遮挡、两手换位和关闭后占用指示。

失败或低于目标必须保留原始计数和偏差，注明影响及后续处理；不能删除失败尝试提高成功率。汇总函数仅算比例，配置版本/哈希混用或未知环境会被拒绝；输出始终需要人工核对来源，不自动授予 PASS。每个版本独立计算，不把较好的环境平均后掩盖失败。

如果需要调整阈值，先形成最小参数假设，保存旧数据，再提高 configVersion、重跑固定序列及本矩阵；不能将未重新测试的旧结果挪到新配置。设备证据仅保存标量、脱敏错误和文字观察；截图前隐藏真实预览，不保存视频、原始帧或完整真人关键点流。结果可以由用户口述后整理，无需手动执行 PowerShell。

最终报告分别列工程实现、自动测试、各实际设备/浏览器结果、未执行项目以及公开发布许可状态。TASK-208/412/612/706/707 的债项和历史事实仍然有效，不能因为生成本表而清除。
