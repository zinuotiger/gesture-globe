# Hand feature geometry

TASK-401 exposes pure image-plane distance, palm center (0/5/9/13/17), palm width (5↔17), bounding box, pinch ratio (4↔8 divided by max(width, epsilon)), velocity in normalized units/second and HandFeatures extraction. Z is copied/averaged for DTO completeness; projected distances use X/Y consistently. No mirror is applied in the algorithm. Reflection preserves width and pinch ratio; pointer mirror belongs in display mapping.

Malformed/incomplete/nonfinite inputs return undefined, never reusable old deltas. A missing or nonpositive previous time interval yields no velocity. Zero palm width has a finite denominator but cannot control. Off-frame, too-small/too-large hand images yield explicit feedback reasons rather than a gesture. Bounding box is recomputed from points, not trusted from stale metadata. Returned points are copies.

M09 defaults use the specification's 2% completeness border and approximately 4%–35% hand image area. The denominator epsilon is 0.000001 normalized image units. These are validated engineering starting values, not human-calibrated results; TASK-412 retains real-human tuning acceptance. Completeness is the fraction of points inside the inset region; being near the border informs quality without silently clamping coordinates.

Dedicated coverage command: `node node_modules/vitest/vitest.mjs run --config tests/vitest.gesture.config.mjs --coverage`. It enforces at least 85% lines, statements, branches and functions on the actual math/extractor files. This is separate from the existing global schema coverage gate; neither is described as whole-application coverage.

TASK-402 PrimaryHandSelector ignores SDK slot identity and follows the nearest valid palm within a configured tracking radius. Quality uses the specification's 0.35 confidence / 0.25 top gesture / 0.20 completeness / 0.20 size starting weights. Matching blends continuity 0.55 with quality 0.45. A valid primary is locked for 500ms; after the lock, a challenger must exceed the continuity score plus a validated margin. No handedness preference is applied. Short loss returns no controlling hand and retains only the prior palm/ID/timestamps; after 180ms a new candidate may take over. IDs are session-local counters, not biological identifiers, and reset with session/reset. Thresholds still await actual human tuning. Invalid, stale or duplicate frames cannot issue a selection; no history of complete landmark arrays is retained by the selector.

TASK-403 TemporalFilter retains one raw/smoothed palm, pointer, ratio and time only. Palm/ratio alpha is 0.25, pointer alpha 0.35. Missing/invalid/stale/order input clears the anchor. Session/hand changes, a gap over 150ms, or raw palm displacement over 0.05 rebuild the anchor with canMove=false and zero delta/dt. Exactly 150ms remains accepted. Subsequent samples use actual capture-time dt. Both current rawDelta and smoothed delta are explicit so gesture modes can suppress EMA settling when the hand actually stops; no previous motion is reused. The pure deadzone helper preserves sign and rejects invalid thresholds; each mode applies its configured speed-space deadzone during mapping. None of these synthetic jitter tests proves real-device latency.
