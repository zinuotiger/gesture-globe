# 真人手势与参数基线：集中验收准备

TASK-412 的真人证据当前为 NOT_RUN / ACCEPTANCE_DEFERRED。本轮只锁定可复核的工程默认参数快照，不宣称完成调参或达到识别率。报告 TASK-412-manual-plan.json 记录 configVersion、实际配置 SHA-256、配置全文和空环境字段；TASK-412-manual-matrix.csv 提供 180 个组合的空白记录。每手势总计至少 20 次独立开始，组合按成本抽样但覆盖左右手、0.5/1/1.5m、明亮/一般/仍可见的较暗光线、简单/一般杂乱背景。不是每组合必须 20 次。

按当前授权，在全部 84 项工程完成后集中操作，当前不要求用户运行命令或先行测试。届时使用最终报告中的本机预览地址，Chrome 与 Edge 分别记录完整版本、机器型号、OS、摄像头型号/实际分辨率、画质、日期和匿名测试者编号；不要记录姓名、设备唯一 ID 或推断身份属性。先完成摄像头允许/拒绝、十次启停和占用指示验收，再进入手势矩阵。

1. 明确点击启用并允许摄像头，等待真实模型 READY；确认未请求麦克风。显示掌心完整入框，记录距离、光线与背景。每次尝试先离开旧手势，再开始新姿态。
2. Open Palm：在 1.5 秒内进入旋转，左右各转一次；停止手部运动后地球不继续转。记录成功、误分类、进入/退出耗时、跳变和重试。总体启动成功率目标 >=90%。
3. Pinch：进入第一帧不跳变，捏住后掌心上下移动能缩放；手不移动只改变指尖间距不应放大缩小。记录方向偏好及是否需反转。总体启动成功率目标 >=90%。
4. Closed Fist：旋转/缩放/指向中握拳，确认当前动作立即结束；握拳移动到另一位置再松开，不继承旧位移，重新稳定后才控制。逐项记录，不编造文档未给出的统一成功率阈值。
5. Victory：稳定手势触发一次复位，保持至少两秒不重复；离开并等冷却后重新开始。复位动画可由鼠标打断。成功率目标 >=85%。
6. Pointing：指针随食指尖平滑运动；背景或 UI 区域不选择。有效地球区域稳定停留约650ms后选择一次；明显移动重计时。快扫20次不得误选，稳定停留20次记录成功率，目标 >=85%。
7. 无手两分钟不得产生地球命令；静止60秒明显误旋转/缩放不超过一次；普通挥手60秒不得触发复位/选点。另记录左右手、两手换位和短遮挡的控制连续性。
8. 结束时关闭摄像头，确认活动轨道为0、预览解绑、Worker退出，并亲自确认浏览器占用指示熄灭。

失败证据只记录时间、配置版本/哈希、匿名环境、动作步骤、标量计数/耗时、错误文字和脱敏调试状态。截图前隐藏真实摄像头预览；不保存/上传视频、原始图像、完整真人关键点流或设备ID。用户可直接回复记录，代理整理，无需 PowerShell。

只有真实数据完成后才讨论参数调整：区分误触发、漏触发、进入慢、退出慢和抖动，每次只改一组参数，保留前后结果，并在真正校准时提升 configVersion。数值汇总函数只计算记录，不授予人工 PASS。当前 configVersion 仍是工程默认版本；模型许可仍 UNRESOLVED，公开发布仍 BLOCKED_PENDING_LICENSE。
