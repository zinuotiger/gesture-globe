# Unified input boundary

TASK-501 introduces InputPort.dispatch, ControlInputIntent and InputRouter as the shared synchronous ingress for gesture/mouse/keyboard/UI/Agent adapters. InputRouter projects known envelope fields into owned immutable data and invokes one handler. INVALID_INPUT, HANDLER_FAILED and DISPOSED are explicit results; handler failure does not block the next dispatch. ACCEPTED at this stage means delivered to the input handler, not executed by Globe.

The input carries schemaVersion, id, source, kind, phase, timestampMs, payload and optional traceId. Kinds are ROTATE, ZOOM, SELECT, PAUSE, RESET, FOCUS, SET_AUTOROTATE and CANCEL. Terminal continuous phases contain no stale movement. Gesture payload additionally carries sessionId, sourceHandId and confidence; raw landmarks/private model fields are forbidden. SELECT remains a normalized pointer stream, not a geographic selection.

createInputAdapter binds mouse/keyboard/UI/Agent to one port, injected clock and nonblank per-lifecycle namespace. The owner must provide a distinct namespace for concurrent instances of the same source. Sequence IDs are deterministic, no random/timer behavior. gestureToInput accepts only the public GestureIntent, preserves ID/time/trace and maps delta.x/y to yaw/pitch or palm-Y zoom. Caller provides measured dt; it cannot manufacture an UPDATE from zero/invalid elapsed time. NONE is inert.

Shape normalization currently validates metadata, finite plain data, allowed fields, phase and pointer bounds. It does not grant source priority or command execution. TASK-502 adds ownership locks; TASK-503 adds payload completeness, range/freshness and command mapping; TASK-504 adds rate/dedup. Actual DOM/Orbit integration remains TASK-505/506, and complete wiring TASK-508. The Agent adapter contract is available for later implementation while the product feature remains off; this creates no external service capability or credentials.

TASK-502 SourceLockManager grants equal highest priority to mouse/keyboard/UI, then gesture, then Agent. Accepted manual input renews the configured 800ms lease; denied lower-priority requests cannot extend it. Equal-priority manual sources can take over immediately. Gesture ownership expires after the existing lostHandMs (180ms); Agent uses the bounded configured 800ms idle lease and remains preemptible. Every query/dispatch advances an explicit monotonic timestamp and expires stale ownership; no independent timer or infinite lock exists.

Fist's gesture-only pause is refreshed from each current frame's clutch state and expires after missing frames for lostHandMs. It clears gesture ownership without blocking UI/mouse/keyboard. A caller must not issue ordinary pointer-up as explicit release: the manual suppression interval survives until lease expiry. release is for explicit source cancellation; cancelAll is unconditional lifecycle/Esc cleanup. Decisions include preempted owner for later source-change/cancellation integration. Invalid clocks cannot move deadlines backwards or create nonfinite leases. This manager decides ownership only; it does not execute camera commands or enable Agent.

TASK-503 mapIntent validates payload completeness, future/stale timestamps (gesture 150ms, other sources commandMaxAgeMs), geography/distance and Agent feature policy before producing an action. Input, nowMs and command execution must use the same monotonic clock; no implicit timestamp conversion is performed. Continuous deltas are divided by measured dt, velocity-clamped, then multiplied by capped dt. START with nonzero motion is invalid; valid START and END/CANCEL become control lifecycle actions without a movement command.

Gesture Pinch delta is logarithmic distance, whereas the existing Globe command/executor uses linear distance increments. The mapper uses the supplied current view distance and expm1(logDelta), then applies the configured distance-speed cap. Small motion is proportional across distances and frame rates; large motion remains bounded. Other source zoom payloads use the existing linear increment contract. No CameraRig API is changed. Every generated GlobeCommand passes its existing public validator. IDs are source-namespaced and traceId is preserved. SELECT emits only a pointer/cancel request for future Geo hit/dwell; PAUSE is gesture-only. Mapping is not authorization to execute: source lock, dedup/rate and integration remain separate stages.

TASK-504 CommandRateLimiter stores at most one ROTATE and one ZOOM aggregate, flushes at configured commandHz (60 cycles/second), and never queues discrete actions. Like-source/like-trace movement sums within capped dt/velocity; source takeover clears old slots and a new trace replaces its old slot. Oldest capture time is retained so coalescing cannot hide stale age. Invalid, out-of-order and duplicate motion is rejected. cancel(source) or cancel() drops pending motion immediately without a tail flush; integration must call this on END/CANCEL, preemption, pause and lifecycle stop.

Discrete commands return immediately and cancel buffered motion. Their accepted IDs use a dedicated FIFO of maxDiscreteIds (256), separate from high-frequency motion IDs; motion cannot evict RESET/FOCUS dedup history. Both histories are bounded to their stated recent-ID capacity, not an unlimited lifetime guarantee. Stale checks further constrain delayed replays. A disposed buffer accepts nothing. All time is supplied; rendering/dispatch integration owns flush calls, no timer creates fake input. Selection IDs are governed by Geo, which can use the same bounded Deduplicator for its discrete edge.

TASK-505 OrbitControls operates on a private proposal camera. Only validated commands can mutate the authoritative CameraRig/rendered camera. A canvas-only start sends CANCEL and disables auto-rotation through the M06 mouse adapter. Per-render proposals include measured dt; CommandBus validates and obtains the shared manual lease before the Globe sink. Large wheel requests converge toward the bounded Orbit target at the configured speed rather than bypassing the limiter. Other accepted commands clear Orbit momentum; mouse-origin execution preserves it. Disable/dispose clears retained proposals/listeners. Missing input sink leaves controls unbound (fail closed).

The current CommandBus is the minimum synchronous mouse ingress. UI/keyboard replacement and general lifecycle/source event/rate-buffer composition are TASK-506/507; this task does not claim those future features. A rejected execution is explicit and never reported as executed. Browser regressions exercise actual Three.js controls and command rejection; they are not human/device acceptance evidence.

TASK-506 binds bubble-phase keyboard shortcuts: arrows rotate, +/- zoom, R resets, Esc cancels. A focusable canvas enables a deliberate keyboard target. Input/textarea/select/button/link, ARIA input widgets, inherited contenteditable and shadow-DOM editable paths retain native keys. Already-consumed, composing, Alt/Ctrl/Meta events are ignored; repeated reset/Esc are suppressed while movement repeat remains a semantic step. No key is prevented unless accepted or an injected higher-priority Escape consumer handles it. The consumer seam is for subsequent dialog/selection integration; Esc never closes the camera here. Binding returns an explicit disposer.

UI buttons and keyboard use createStepInput with distinct source identities and the same CommandBus, validated configured steps and manual lease. Legacy controlCommand remains a pure compatibility utility/test fixture, no longer used for live UI dispatch. No global synthetic clicks, DOM-to-camera mutation or microphone request is introduced. P1 H/help wiring is outside this card.

TASK-507 CommandBus (also exported as InteractionOrchestrator) now owns bounded rate/dedup, lifecycle actions and source arbitration together. Commands and SOURCE_CHANGED/SOURCE_CANCELLED/COMMAND_RESULT/INPUT_REJECTED events preserve traceId; absent traces derive from the stable control session, never random IDs. Event observers cannot break execution; their failures count explicitly. Command sink failures remain rejected events; subsequent commands continue.

Manual takeover cancels old ownership/selection/Agent hooks and active view transitions before buffering movement. START establishes a fresh control scope; END/CANCEL, source expiry, clutch, explicit cancel and lifecycle/dispose clear queued movement without a tail. Clutch affects only gesture, and a late terminal from a former source cannot stop the current manual transition. SELECT remains a validated pointer callback until Geo supplies hit/dwell. The default Agent feature remains off; enabled Agent in deterministic contract fixtures is not external integration.

Continuous dispatch ACCEPTED means admitted to the bounded buffer; COMMAND_RESULT distinguishes execution. Scene's render hook flushes the queue, and disabling Orbit sends source cancellation as well as clearing its private damping. UI displays only source changes through a small scalar indicator. No raw frames/landmarks or unbounded intent history are retained. Esc's dialog/selection priority seam remains available for subsequent UI/Geo composition.
