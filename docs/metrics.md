# 指标统计口径

TASK701 仅完成采集和统计机制；不把自动测试中的浏览器性能数值作为参考设备验收。

- 默认5秒滑动窗口、每类最多600个数值样本，来自验证配置；插入O(1)，快照复制有限数值再排序。窗口边界包含恰好5秒的样本。
- 中位数：奇数中间值，偶数中间两值平均。P95：升序序列的 `ceil(0.95*n)` 项（1基）。平均值算术平均，latest为时间顺序最后值。空窗口全部统计为null，不伪造0ms或0FPS。
- Render FPS：实际 renderer.render 返回后的相邻观察间隔，`1000 / mean(frameMs)`；这是提交节奏估算，不是显示器呈现/光子级测量。渲染异常不生成完成样本；观察者异常计数但不打断渲染。
- Inference FPS：应用收到有效推理结果的间隔；inferenceMs独立来自真实Vision DTO。两者不能相互替代。过期结果不驱动控制，其丢弃另计。
- droppedBusy、stale、rate-limited、unavailable及submitted是当前runtime生命期累计标量，分别显示，不把限频等同于推理失败。
- 页面可见性变化清空间隔基线，推理暂停/停止/重新初始化清空推理窗口；恢复首事件不能形成虚假的长间隔。dispose清空并拒绝后续采集。窗口过期后恢复unknown。
- 正常计时使用Window/Worker统一epoch的Performance API。缺失、无效或抛错时使用不倒退的Date基础计时；精度降低，不用于声明高精度延迟达标。
- 诊断模块仅接收注入数值配置及标量事件，不持有帧、ImageBitmap、landmarks、设备ID或DOM。App负责公开模块接线，未添加依赖。

浏览器集成使用明确合成的空视频流但运行真实本地SDK/模型，验证采集不是静态假数；不证明真人识别或真实设备FPS/P95达标。实际设备性能/稳定性留给TASK707/708集中验收。延迟分阶段关联、低频面板、健康告警和自适应由后续702–704完成。
