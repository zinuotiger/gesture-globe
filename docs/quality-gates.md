# Local quality and clean verification

Use Node 24 and the committed exact package-lock. Run npm ci, npm run assets:fetch, and use an already provisioned matching Playwright Chromium binary with its cache inside the repository. Missing browser provisioning is a failed/unrun environment check, not PASS. Agent runs use trusted installed Node/npm, with no npx runtime substitution. `npm run quality` executes lint, format check, strict TS, unit/contract/integration, coverage, build and two-viewport E2E sequentially. Actual commands, exit codes, output, timestamps and skipped checks are recorded in `.gesture-globe/reports/build-report.json`. A failed check stops subsequent checks and exits nonzero.

The final release:verify must currently exit 2 for the explicit model license blocker. The report calls that EXPECTED_BLOCK, never release PASS. Public release and manual acceptance are independent fields. CI invokes the same runner and uploads the report even on failure; no remote CI is claimed until actually run.

`npm run quality:clean` creates an independent local clone without hard links in the ignored .gesture-globe/clean-verification directory, overlays the exact current nonignored working files, runs npm ci into an empty dependency directory, performs its own official assets:fetch, then runs the complete quality gate. Source checkouts cannot be placed under node_modules because Node refuses TypeScript stripping there. It does not copy the host node_modules or model. The npm archive cache and pinned browser executable may be reused; browser profiles and dependency resolution/install are fresh. It compares the original host HEAD, Git status and state ledger, preserves output in clean-build-report.json, then removes only its own temporary directory. It never commits or edits the host Git index. All caches/temp/output stay inside this repository. This is a fresh installation proof of the current working source, not a claim that the intentionally dirty host is clean.

MS-0 additionally requires its controller milestone report and recorded PASS. Future camera/human/visual/performance gates are not covered by automated quality. The release blocker is tracked in MS-7-release-blockers.md.
