# 设置与本地偏好

设置面板即时控制画质、摄像头预览和骨架显示、自动旋转、减少动画、手势灵敏度及旋转反转。改变这些设置不会开启摄像头。画面隐藏不等于关闭，面板提供明确关闭入口。

仅 gesture-globe.preferences.v1 的完整 storageVersion=1 白名单 DTO 可保存；无设备ID、权限结果、模型对象、帧或关键点。损坏/不兼容内容只清除本键。存储受限时保持会话内功能并提示；恢复默认只清除偏好键和教程完成键，其他站点数据保留。

灵敏度0.5–2只缩放已识别的旋转/缩放意图，反转相对基础配置计算一次；识别阈值不变。UI不直接操作Three.js，自动旋转仍通过M06；已成功开启的旋转设置不会因其动作锁到期撤销，后续手动/手势输入照常停止它。系统 prefers-reduced-motion 和本地减少动画选项取逻辑或：关闭auto，取消当前大过渡，后续复位/聚焦立即到达有效终点。退出减少动画不会自动启动运动。

自动测试见TASK611证据。真实体验、设备、真人及人工视觉仍待最终集中验收；模型公开许可仍UNRESOLVED。
