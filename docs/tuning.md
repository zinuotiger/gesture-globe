# 参数调整与证据

唯一运行配置入口是 [defaults.ts](../src/config/defaults.ts)；[numericRules.ts](../src/config/numericRules.ts) 定义单位与合法范围，schema检查类型、非有限数、未知字段和跨字段约束。当前 configVersion 是工程版本，不是实机校准证明。早期证据绑定旧版本，不能回写。

先确定问题发生在摄像头就绪、推理耗时、分类、手势状态机、交互仲裁还是渲染，使用脱敏错误码和阶段指标定位。不要用提高超时掩盖阻塞，也不要把缺失数据当作零延迟。模型启动耗时和整个测试耗时是不同数值。

记录基线：配置完整快照/SHA、匿名设备环境、独立尝试次数、成功/失败、误触发、进入/退出延迟与方向偏好。按 [最终真人矩阵](final-gesture-validation.md) 覆盖左右手、距离、光线和背景。

每次只改变一组有依据的参数。Open Palm查看分类进入/保持阈值及稳定帧；Pinch区分几何比例滞后与掌心位移缩放；Fist检查离合优先级和松拳锚点；Victory检查离开重武装和冷却；Pointing区分安全区域、平滑和停留取消。灵敏度与轴向反转是用户偏好，不能用于捏造识别率。

真实调参时提高 configVersion，保存前后结果，重新运行固定序列、契约、集成、浏览器和相关质量门禁，再复测真人矩阵。阈值改变不能通过删除失败序列、提高容忍度或复用旧配置证据获得 PASS。遇到功能/语义/架构变化先走明确需求变更控制。

自适应画质/Hz由配置管理，达到压力条件才降档，恢复条件更保守；不通过不断重建摄像头或 Worker 提升表面指标。性能证据按 [稳定性协议](stability-validation.md) 记录分布、采样局限和真实设备，不报告孤立的一次 FPS 作为达标。
